# 502. IPO

[:paperclip: LeetCode Problem Description](https://leetcode.com/problems/ipo/description/)

## Solution: Greedy Approach with Two Heaps (Min-Heap and Max-Heap)

We can solve this problem greedily. At each step, we want to choose the project that yields the **maximum profit** among all projects we can currently afford. We can implement this efficiently in $O((N + K) \log N)$ time using two heaps: a min-heap for required capital and a max-heap for profits.

### Thought Process

1.  **Greedy Choice**:
    *   To maximize final capital, we should always choose the project with the highest profit among all the projects we can afford with our current capital $w$.
2.  **Two-Heap Structure**:
    *   **Min-Heap (`MinCapitalHeap`)**: Holds projects as `[capital, profit]`, sorted ascendingly by capital. This allows us to quickly query which projects we can currently afford.
    *   **Max-Heap (`MaxProfitHeap`)**: Holds the profits of projects we can afford, sorted descendingly.
3.  **Algorithm**:
    *   Initialize both heaps and push all projects onto `MinCapitalHeap`.
    *   Loop up to $k$ times (selecting up to $k$ projects):
        *   While `MinCapitalHeap` is not empty and the top project's required capital is less than or equal to our current capital $w$:
            *   Pop the project from `MinCapitalHeap` and push its profit into `MaxProfitHeap`.
        *   If `MaxProfitHeap` is empty, we cannot afford any of the remaining unstarted projects. Break the loop early.
        *   Pop the maximum profit from `MaxProfitHeap` (our best greedy choice), add it to our capital $w$, and proceed to the next selection step.
    *   Return the final capital $w$.

### Go Code

``` go
import "container/heap"

type MinCapitalHeap [][]int
func (h MinCapitalHeap) Len() int { return len(h) }
func (h MinCapitalHeap) Less(i, j int) bool { return h[i][0] < h[j][0] }
func (h MinCapitalHeap) Swap(i, j int) { h[i], h[j] = h[j], h[i] }
func (h *MinCapitalHeap) Push(x interface{}) { *h = append(*h, x.([]int)) }
func (h *MinCapitalHeap) Pop() interface{} {
    last := (*h)[len(*h)-1]
    *h = (*h)[:len(*h)-1]
    return last
}

type MaxProfitHeap []int
func (h MaxProfitHeap) Len() int { return len(h) }
func (h MaxProfitHeap) Less(i, j int) bool { return h[i] > h[j] }
func (h MaxProfitHeap) Swap(i, j int) { h[i], h[j] = h[j], h[i] }
func (h *MaxProfitHeap) Push(x interface{}) { *h = append(*h, x.(int)) }
func (h *MaxProfitHeap) Pop() interface{} {
    last := (*h)[len(*h)-1]
    *h = (*h)[:len(*h)-1]
    return last
}

func findMaximizedCapital(k int, w int, profits []int, capital []int) int {
    minCapital, maxProfit := MinCapitalHeap{}, MaxProfitHeap{}
    heap.Init(&minCapital)
    heap.Init(&maxProfit)

    for i := 0; i < len(profits); i++ {
        heap.Push(&minCapital, []int{capital[i], profits[i]})
    }

    for range k {
        for minCapital.Len() > 0 && minCapital[0][0] <= w {
            item := heap.Pop(&minCapital).([]int)
            heap.Push(&maxProfit, item[1])
        }
        if maxProfit.Len() == 0 {
            break
        }
        w += heap.Pop(&maxProfit).(int)
    }
    return w
}
```

### Code Efficiency

- **Time Complexity**: $O((N + K) \log N)$
    - Pushing all $N$ projects into the `MinCapitalHeap` takes $O(N \log N)$ time.
    - Each project is pushed onto and popped from both heaps at most once. Across $K$ iterations, the total heap operation cost is bounded by $O((N + K) \log N)$.
- **Space Complexity**: $O(N)$
    - The heaps store up to $N$ projects/profits, requiring $O(N)$ auxiliary space.
